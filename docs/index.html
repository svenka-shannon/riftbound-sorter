System Architecture & Physical Layout

Block diagram + top-down physical layout. Machine fits within 580×540mm (under 2ft×2ft).

System Architecture + Physical Layout v0.1 — block diagram (left) and top-down physical footprint (right). Hopper top-left, conveyor center, scanner mid-conveyor, sort gate + bins right.

Wiring Diagram

All Dupont connectors — no soldering required. 5V + 12V rails. 7 GPIO pins total.

Wiring Diagram v0.1 — Pi Zero 2W → PCA9685 (I²C), HX711 (GPIO 5/6), relay (GPIO 17), L9110S (GPIO 23–26), servos, vacuum pump, camera (CSI).
Wiring Diagram SVG — vector version with component labels and wire colors.

Software Architecture

Main loop flow + full Python stack. JSON rules engine, Riftcodex API (free), SQLite inventory, Flask web UI.

Software Architecture v0.1 — main loop (left): pick → weigh → transport → capture → identify → route → log. Stack layout (right): hardware layer, vision, API, rules engine, web UI.

3D Printed Parts

9 OpenSCAD files. All parts fit Bambu P1S (256×256mm bed). Conveyor rails split 2×190mm with alignment pins.

3D Print Specs v0.1 — 28 parts, ~30 hrs total, ~390g PLA (~$8). Hopper exit slot 0.65mm (single-card feed). PETG for suction arm and gate levers.

Code Structure
